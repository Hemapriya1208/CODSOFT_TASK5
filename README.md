# CODSOFT TASK 5 – Web Data Extraction & Analysis

## Project Overview

This project uses **web scraping** to collect book data from *Books to Scrape* and analyze it using Python.

## What I Did

- Scraped **1,000 books** from 50 pages.
- Extracted title, price, rating, and availability.
- Cleaned and processed the collected data using Pandas.
- Analyzed prices and ratings.
- Created visualizations to identify patterns and trends.
- Exported the final dataset to CSV and Excel.

## Technologies Used

Python • Requests • BeautifulSoup • Pandas • Matplotlib • Seaborn

## Key Results

- **1,000 books** collected
- **Average price:** 35.07
- **Average rating:** 2.92
- **No missing values or duplicate records**

## Output Files

- scraped_books.csv`
- scraped_books.xlsx`

## Conclusion

This project shows how web scraping can transform online information into structured data and useful insights through data cleaning, analysis, and visualization.
